# Nexus VPN

Nexus VPN is a secure, modular VPN system built around WireGuard.

## Core Features

- WireGuard-based encrypted tunnel
- Multiple VPN servers
- Server switching
- Parallel server health checks
- Automatic server selection
- Kill switch
- DNS leak protection
- IPv6 leak protection
- Device-specific keys
- Connection monitoring
- Traffic monitoring

## Architecture

Nexus VPN separates the VPN client,
VPN gateway, server management, and security controls
into modular components.

## Principles

- Security by design
- Strong, proven cryptography
- Minimal data exposure
- Device ownership and user control
- Auditable security actions
- No custom cryptographic protocol
